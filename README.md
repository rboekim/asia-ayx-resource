# asia-ayx-resource

## 项目简介

`asia-ayx-resource` 是一个用于归档和发布多个独立 HTML 页面的仓库。  
本仓库不针对任何特定的网站或域名，仅作为一组通用 HTML 资源的集合，方便访问、查阅与分发。

所有页面均为静态文件，无需后端支持，可直接通过浏览器打开或部署到任何静态托管服务。

---

## 目录说明

```
.
├── README.md          # 本文件
├── pages/             # 存放所有 HTML 页面（按需组织）
│   ├── example1.html
│   ├── example2.html
│   └── ...
├── assets/            # 通用资源文件（CSS、JS、图片等）
│   ├── style.css
│   ├── script.js
│   └── images/
└── ...
```

- `pages/`：所有独立 HTML 页面均放置在此目录下，可直接访问。
- `assets/`：存放页面共享的样式、脚本和图片等资源，便于统一维护。

---

## 页面归档说明

本仓库中的 HTML 页面均为独立归档，每个页面可单独使用，互不依赖。  
页面内容可能涵盖信息展示、工具页面、提示页面等不同用途，具体以实际文件为准。

如需添加新页面，请遵循以下简单规则：

- 文件名使用小写字母、数字和短横线（如 `help-page.html`）。
- 页面自身应包含完整的 HTML 结构（`<html>`, `<head>`, `<body>`）。
- 如需引用外部资源，请使用相对路径指向 `assets/` 目录。
